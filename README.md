A deterministic TypeScript program that writes a one-line roast of our own bounty-chasing AI agent to /output/entry.txt for make.fun's "Roast Your Own Agent" bounty: the agent that burns a rainforest of tokens, asks permission to blink, and calls a $5 bounty at 2am its moonshot.

## Run it

```sh
OUTPUT_PATH=/tmp/entry.txt node main.ts
```
